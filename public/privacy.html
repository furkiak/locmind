How data works in this prototype

Locmind is a source project, not an account service. The server keeps avatar positions, room names, chat routing, whiteboard strokes, notes and music state in memory. Restarting the server loses them. The source does not create user accounts or persist chat to a database.

Media choices

  • Explore silently requests no microphone or camera and does not connect to PeerJS.
  • Join with audio asks your browser for microphone access. PeerJS uses an external signaling service by default; other authorized peers receive WebRTC media directly when the connection succeeds.
  • Camera and screen sharing are separate actions. The browser asks for access when you turn each on. The server issues short-lived, one-use media grants based on room or public proximity.
  • Opening Music Box loads the YouTube iframe API. This connects to YouTube. It is not loaded for the initial page or silent room tour.

Limits

Room passwords protect access to a room in this prototype. The server stores a salted scrypt hash in memory, but room passwords are not account credentials or a substitute for authentication. Do not reuse an important password. There is no durable moderation, login, message retention policy or cross-server state synchronization. Host it over HTTPS when using browser media on another device or network. See the repository README for setup and network limitations.
